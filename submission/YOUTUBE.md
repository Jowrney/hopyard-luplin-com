## Title

Hopyard Designer — Human-Agent Hopyard Design with WebMCP

## Description

Hopyard Designer by HOPEDEN is a shared planning workspace for hop farmers, installers, and AI agents.

The existing product calculates seed cost, facility quantities, preliminary structural loads, real-time estimates, and synchronized 2D/3D farm views. During the OpenAI WebMCP Challenge, it was extended with a non-destructive human-agent design workflow.

An agent can:
- read the current design context;
- inspect Korean and North American reference systems;
- simulate deterministic alternatives without overwriting the baseline;
- show up to three candidates in the comparison tray; and
- preview a candidate in the same 2D/3D workspace used by the farmer.

Apply and Discard tools are registered only during preview, changing the tool surface from 5 to 7 tools and preserving the farmer's final decision.

Live demo: https://hopyard.luplin.com/design/demo
Source: https://github.com/Jowrney/hopyard-luplin-com

Built by HOPEDEN Agricultural Corporation.
